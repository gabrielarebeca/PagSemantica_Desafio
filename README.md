# 🌐 Página Semântica - Desafio

Este projeto é um **desafio de construção de uma página web utilizando HTML semântico e CSS**, com foco em boas práticas de estruturação de conteúdo e acessibilidade.

## 📌 Sobre o Projeto

A proposta foi desenvolver uma página web responsiva, aplicando **tags semânticas do HTML5** para organizar corretamente as seções da interface (como `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, etc.), além de aplicar **CSS** para estilização visual.

## ⚙️ Principais Elementos

- 🧠 Uso de **tags semânticas** para melhorar a compreensão do conteúdo por leitores de tela e motores de busca  
- 🎨 Estilização com **CSS3** para layout, cores, espaçamento e fontes  
- 📱 Estrutura compatível com diversos tamanhos de tela  
- 🧩 Organização clara e separada entre conteúdo e estilo

## 🛠 Tecnologias Utilizadas

- **HTML5 (semântico)**
- **CSS3**
